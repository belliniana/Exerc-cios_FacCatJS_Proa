# FACCAT - Exercícios de Lógica em JavaScript

Repositório independente com os exercícios da FACCAT.

## Conteúdo

- Exercícios 5 ao 39
- HTML, CSS e JavaScript puro
- Botão para executar cada exercício
- Entrada de dados pelo navegador
- Exibição do resultado na própria página
- Visualização do código JavaScript de cada solução

## Como executar

Abra o arquivo `index.html` no navegador.

## Estrutura

```text
FACCAT_JavaScript/
├── index.html
├── styles.css
└── js/
    ├── utils.js
    ├── ui.js
    └── faccat.js
```
